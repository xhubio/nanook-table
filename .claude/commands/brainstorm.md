# /brainstorm

Startet eine strukturierte Brainstorming-Session fuer ein neues Feature oder eine technische Entscheidung.

## Verwendung

```
/brainstorm <Thema oder Feature-Beschreibung>
```

## Was passiert

1. Liest den `brainstorming` Skill (`.claude/skills/brainstorming/SKILL.md`)
2. Fuehrt eine interaktive Brainstorming-Session durch
3. Erstellt ein Design-Dokument in `REQUIREMENTS/PLAN/`

## Naechste Schritte

Nach dem Brainstorming: `/write-plan` um den Plan auszuarbeiten.

---

**Skill-Referenz**: Fuehre den Skill `brainstorming` aus mit dem angegebenen Thema als Kontext.
